DebTec — Sistema de Gerenciamento de Tarefas

 1. Sobre o projeto
Debtec é um sistema web desenvolvido com o objetivo de facilitar o gerenciamento e o acompanhamento de tarefas em equipes, especialmente no setor de logística.
A plataforma permite cadastrar, visualizar, editar, excluir e acompanhar tarefas, contribuindo para a organização e produtividade da equipe.

2. Objetivo
Desenvolver uma aplicação web que permita controlar o fluxo de trabalho, identificar tarefas prioritárias e acompanhar o andamento das atividades.

3. Escopo inicial
O sistema contará inicialmente com:
- Cadastro de tarefas.
- Listagem de tarefas.
- Edição de tarefas.
- Exclusão de tarefas.
- Definição de prioridades.
- Controle de status das tarefas.

4. Metodologia ágil
Será utilizada a metodologia Kanban para organizar e acompanhar as atividades do desenvolvimento.
O quadro será dividido em três etapas:
- A Fazer (To Do).
- Em Progresso (In Progress).
- Concluído (Done).

5. Tecnologias utilizadas
- Python.
- Flask.
- HTML.
- CSS.
- JavaScript.
- SQLite.
- Pytest.
- Git e GitHub.
- GitHub Actions.

6. Mudança de escopo
Durante o desenvolvimento, será simulada uma alteração no escopo inicial por meio da inclusão de uma funcionalidade de acompanhamento de desempenho das tarefas.
A mudança será registrada no quadro Kanban, documentada neste arquivo e implementada por meio de um novo commit.

7. Como executar
As instruções completas de instalação e execução serão adicionadas após a implementação do sistema.

Mudança de escopo
Durante o desenvolvimento, foi identificada a necessidade de ampliar a visualização das atividades. Por isso, foi adicionada uma funcionalidade de painel de indicadores.
O painel apresenta:
- Quantidade total de tarefas cadastradas;
- Quantidade de tarefas pendentes;
- Quantidade de tarefas em andamento;
- Quantidade de tarefas concluídas.
Essa melhoria facilita o acompanhamento das atividades e permite visualizar rapidamente o andamento do trabalho.

Justificativa
A mudança foi incorporada para tornar o sistema mais organizado e oferecer uma visão geral da produtividade, agregando valor ao projeto sem comprometer sua proposta inicial.
